🎓 EDUSITY - EDUCATIONAL WEBSITE USING REACTJS
Welcome to Edusity, a fully responsive educational website built with ReactJS. It features modern UI/UX, smooth navigation, and interactive elements for showcasing programs, campus galleries, testimonials, and contact forms — perfect for universities or educational institutions.

🚀 Project Description
This is a fully functional Educational Website built using ReactJS and React Router.
It allows users to browse programs, view campus photos, read student testimonials, watch introduction videos, and get in touch with the institution through a contact form.

🛠️ Features
🏠 Homepage — Beautiful hero banner with an introduction.

🎓 Programs Section — Showcase Graduation, Master's, and Post Graduation programs.

🔍 About Section — Video pop-up and detailed university introduction.

🖼️ Campus Gallery — Image gallery with a 'See More' button.

🌟 Testimonials — Sliding carousel to view student reviews.

✉️ Contact Form — Message submission using Web3Forms.

📜 Navbar & Footer — Smooth scrolling and sticky navbar.

🎥 Video Player — Embedded video modal popup.

🛠️ Technologies Used
Frontend: ReactJS, React Router, React Hooks

Styling: CSS, Custom Assets

State Management: React useState, useRef

API Integration: Web3Forms for contact form handling

🛠️ Installation & Setup :

1. Clone the repository:
https://github.com/HemalathaNunavath/edusity.git

2. Navigate to the project folder: 
cd edusity

3. Install dependencies:
npm install

4. Start the development server:
npm run dev
